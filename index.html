01 / Install & launch

Use your existing Codex CLI and sign-in. Follow the one-command uvx launcher or Python instructions; the wheel installs without Git. Desk opens a local browser workbench.

02 / Find your session

Your recent work appears on the first screen. Choose Resume conversation beside the project you want. Read its prior messages and tool results before sending a task. Remember a phrase instead of a title? Find the old answer and read its original context, even after its project folder is gone. Use Browse all conversations for older titles.

03 / Run one next task

Try the verification prompt below. Approve the native command if asked, then inspect the exact output and pass/failure result. For new work, explicitly choose Start new conversation.

04 / Return tomorrow

Close the browser and reopen the printed local URL while Desk’s terminal is running. Choose the same named session. Ctrl+C stops Desk and its running tasks; relaunch with the same environment and Codex home/state settings next time.

Old provider unavailable?

Choose Continue with another provider in an open session, or Review handoff from saved history. Review the visible messages, command/file/MCP evidence and next goal, then select your target profile. This starts a distinct native thread; the original conversation stays intact. A same-thread resume instead uses your current selected settings.

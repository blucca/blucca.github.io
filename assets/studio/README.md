# Blucca studio assets

Homepage-specific artwork and locally served type. Product subpages keep their existing styles.

- `care-handoff.webp`: screenshot of Blucca’s Care Handoff, showing its fictional sample visit.
- `recall-relay.webp`: a crop of Recall Relay’s redesigned Sam-to-Alex sample handoff.
- `shelfproof.webp`: a crop of ShelfProof’s real browser review, showing local OCR and source boxes on Blucca’s fictional retail flyer. The planted price errors and unresolved readings are part of the sample.
- Raincheck, DockProof and SoundWalk covers are original editorial illustrations of the published sample workflows.
- Capture Loop uses the existing `research/capture-loop/gls-parcel.jpg`; Klaus Mueller’s photograph is credited and linked to that project’s `ATTRIBUTION.md` (CC BY-SA 3.0).
- Bricolage Grotesque and Instrument Sans: Latin variable fonts from Google Fonts, under the SIL Open Font License. License texts are alongside each font.
- `social.png`: raster version of the studio’s original vector banner for link previews.

- `hauspost.webp`: actual HausPost browser, showing the original Apertus 8B response to a fictional tenant thread. Captured 13 October 2026; model run 38328626014. Source review and corrections remain part of the workflow.

- `eight-again.jpg`: Eight Again running natively in the official Vega virtual device, captured 14 October 2026. Copied from the product’s `site/native-practice.jpg`, a cropped simulator frame. The sample lesson is [Six Step tutorial](https://commons.wikimedia.org/wiki/File:Tutorial_breakdance_-_Six_Step.webm) by **Neil Sweeney**, licensed [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Blucca selected practice sections, transcoded the silent lesson to H.264, prepared a 0.75× version, and cropped/resized the simulator frame for the preview. Native UI and surrounding artwork are by Blucca.

- `forkline.webp`: resized from Forkline’s own final `assets/studio.png`, captured 29 October 2026. Actual browser replay of the local example: one Wait edit, two synchronized futures. Example author labels belong to the local sample. UI, robot artwork and maps are original Blucca work.

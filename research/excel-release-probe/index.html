Try the native workflow

  1. Download the manifest above. Open an empty workbook in Excel for the web.
  2. Open Home → Add-ins → More Add-ins. In My Add-ins, open Manage My Add-ins → Upload My Add-in. Choose the manifest and upload it.
  3. In the pane, choose Create test worksheet. Keep the selected Revenue, EBITDA and Review cells, then choose Save selected outputs and baseline with the name “Approved November”.
  4. Choose Revise test lookup, then Review current release. Download the review report and JSON evidence.
  5. Close and reopen the same workbook. The pane restores the named baseline; choose Review current release again.

For your own test model, select the output cells you review, name the approved baseline and save it. After your next edit or refresh, return to that baseline and review the changed outputs.

What stays in the workbook

The pane snapshots used cells across the workbook: Excel-calculated values, text, formula strings and defined names. Named baselines are stored in the workbook settings; the selected financial outputs are retained with each baseline. Review artifacts download to your browser. Workbook contents are not sent to this site's server.

Excel release review: native task probe

Working prototype for a recurring model-review task: save an approved workbook baseline, return to a later release, inspect selected financial outputs and changed formulas, and download a review report.

Current checkpoint · 24 November 2026

The Office.js probe saves named snapshots in the workbook, reads Excel-calculated values and formula text, restores a saved snapshot on reopening, and exports HTML and JSON. Source syntax and XML schema checks completed. The native Excel run follows account setup.

Native task

  1. Download the Excel task-pane manifest.
  2. In Excel for the web, open an empty workbook, then Home → Add-ins → Advanced → Upload My Add-in. Upload the downloaded manifest.
  3. In the pane, create the synthetic test worksheet. Save the preselected Revenue, EBITDA and Review outputs as “Approved November”.
  4. Revise the test lookup, review the current release, and download the HTML report and JSON evidence.
  5. Close and reopen the same workbook and add-in; restore the saved baseline, then compare again.

The synthetic fixture changes first-match to last-match XLOOKUP. Expected Revenue: 110 → 160; EBITDA: 22 → 32; decision: Review → Pass. Excel performs the calculation. The workbook also includes a FILTER spill and selected-output defined names.

Baselines stay inside the workbook. The probe reads the active worksheet and the selected output cells. This HTTPS page serves the task pane's code.
